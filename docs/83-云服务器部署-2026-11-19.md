## 2. 部署步骤（实际执行）

1. **装 Docker + 国内加速**：加阿里云 `docker-ce` EL8 源装 `docker-ce/docker-ce-cli/containerd.io/docker-compose-plugin`；
   Docker Hub 直连超时，写 `/etc/docker/daemon.json` 的 `registry-mirrors`
   （`docker.m.daocloud.io` / `docker.1panel.live` / `docker.1ms.run`），成功拉取 `node:24-alpine`。
2. **上传发布包**：`scp dist/safe-office-0.53.3-20261119.tar.gz root@101.132.160.81:/opt/safe-office/`
   → 解压到 `/opt/safe-office`（含 Dockerfile、docker-compose.yml、prototype/）。
3. **准备数据与配置**：
   - `prototype/data/users.json`：预置 **admin（管理员）+ 已启用 TOTP**（密码与二维码通过安全渠道交付，不写仓库）；
   - `prototype/config.env`：仅 `SAFE_OFFICE_AUTH=required`，**不配置真实 SMTP/IMAP/模型/打印机**（公网机器不落真实凭据）；
     compose 已设 `SAFE_OFFICE_TRUST_PROXY=1`、`SAFE_OFFICE_HOST=0.0.0.0`、端口仅映射 `127.0.0.1:7812`。
4. **构建与启动**：`docker compose build` → `docker compose up -d`（镜像 `safe-office-console`，volume `./prototype/data:/app/data`）。
5. **nginx 反代 + TLS**：`/etc/nginx/conf.d/safe-office.conf`
   80 端口 `server_name 101-132-160-81.sslip.io` → `proxy_pass http://127.0.0.1:7812`（64 MB 上传上限、透传 `X-Real-IP`/`X-Forwarded-*`）；
   `certbot --nginx -d 101-132-160-81.sslip.io --redirect` 签发并部署证书（无邮箱注册）。

## 4. 安全边界（材料里如实写）

- 后端**只绑 127.0.0.1**，只有 nginx 对外；**不要把 7812 直接映射公网**。
- 强制登录（`SAFE_OFFICE_AUTH=required`）+ `admin` **TOTP 两步验证**；登录失败限流（1 分钟 5 次）。
- 公网实例**不配真实 SMTP/IMAP/模型/打印 key**：业务动作全部模拟，邮件/云上传不会真发。
- `data/` 卷含 `users.json`（含 TOTP 密钥）、审计链、附件：需备份并控制服务器访问权限。
- `sslip.io` 是**公共通配 DNS 服务**，仅用于演示；正式材料建议换自有域名（证书可复用 certbot）。
- 证书 90 天；宿主**没有 certbot 自带 timer**，已加 `/etc/cron.d/certbot-renew` 每日 03:00
  `certbot renew --quiet --deploy-hook "systemctl reload nginx"`，`certbot renew --dry-run` 已通过。
  nginx 配置已通过 `nginx -t` 并 reload，未改动既有站点。
