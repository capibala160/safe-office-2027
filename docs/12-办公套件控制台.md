# 办公套件控制台（v0.12 · 演示级最小套件）

> **v0.13 注记**：工具目录已接入 `tool-registry.cjs`；默认控制台仍是 13 个内置工具、行为不变；自定义/MCP 工具见 [工具注册表与 MCP](13-工具注册表与MCP.md)。

更新：2026-10-18。范围：本机 Web 控制台 + 10 个页面；后端复用 v0.9–v0.11 的安全机制。**业务动作全部模拟**，WS63 是虚拟设备，未接真实邮件/打印/门锁/SLE。

> 目标：给 4C 2027 / 毕设一个可点击、可演示的"办公套件"入口，同时把五道闸、冻结操作、WS63 确认、审计、风险治理原样露出来。
> 不是产品级 Office：没有文档编辑器/表格/演示/IM/云盘/审批流引擎，也不接第三方办公套件。

---

## 1. 运行

```bash
cd prototype
npm start                 # http://127.0.0.1:7812
# 或 npm run serve
```

- 仅监听 `127.0.0.1`；无登录/多用户；只用于本机演示。
- 零依赖：`node:http` + 原生 HTML/CSS/JS，无构建步骤、无 CDN。
- 数据在内存（`:memory:` SQLite + 内存审计/风险），重启清空；治理报告即时生成。

## 3. 架构

```
浏览器（public/：index.html + styles.css + api.js + ui.js + app.js + views.js）
        │ fetch JSON（同源）
node:http  server.cjs（127.0.0.1:7812）
        │
ConsoleService（src/console-service.cjs）
  ├─ PolicyEngine / AuditLog / RiskMeter / GuardedPlanner / MockLLM / PerfMeter
  ├─ AgentRuntime（常驻；v0.12 新增转交缝）
  ├─ OperationStore(':memory:') + FulfillmentService + DemoExecutor
  └─ NearfieldConfirmer + VirtualDevice（真实 SFC1/HMAC，虚拟设备）
```

### 3.1 运行时"转交确认"缝

`runtime.cjs` 新增 **默认关闭** 的 `deferActions` / `onDeferred`：

- 位置：规划、闸1/2/3/5、令牌、沙箱、风险冻结检查**之后**，闸4**之前**；
- 命中转交集合（`sendInternalEmail` / `sendExternalEmail` / `deleteDoc` / `printDoc` / `deviceControl`）时，不再执行模拟闸4/副作用，而是把已过闸的 `args/payload/角色/文档/密级` 交给控制台；
- 控制台创建**冻结操作记录**，再走 `FulfillmentService`：
  - 内网邮件：策略自动确认（`confirmationId='policy-auto'`），不弹设备；
  - 外发/删除/打印/设备：WS63 虚拟确认（SFC1 CHALLENGE/DECISION，真实 HMAC）。
- 默认 `deferActions=null` 时逐字节保持 v0.11 行为；原 123 项测试全部保留。

### 3.2 校验与消费语义

- 设备确认沿用 v0.11：`STATE → TASK → NONCE → REPLAY → EXPIRED → MAC → DEVICE → OPERATION → DECISION → OK`。
- nonce 只在成功/取消/过期/超时时消费；MAC/DEVICE/OPERATION 失败不消费，pending 保留。
- 冻结记录 `operationHash` 直接作为挑战 `target_hash`；确认/发送前 `verifyOperation` 复核正文/附件/收件人/来源/密级。
- 取消 → 操作 `rejected`；超时 → 操作仍 `frozen`，可重新发起；重放 → `STATE`；篡改帧 → `MAC`。

## 4. HTTP API（摘要）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | state + 角色/工具/文档/样例/操作/挑战 |
| GET | `/api/state` | 顶栏/右栏/工作台快照 |
| POST | `/api/commands` | 执行命令；返回 lines/gateSummary/operations |
| GET | `/api/documents` `/api/documents/:id` | 文档/生成稿；未读入不返回正文 |
| GET | `/api/emails`；POST `/api/outbox/:id/reconcile` | 邮件记录；unknown 人工核对 |
| GET | `/api/calendar` `/api/contacts` | 日历；通讯录（脱敏） |
| GET | `/api/operations` `/api/operations/:id` | 操作列表/详情 |
| POST | `/api/operations/:id/challenge` `/reject` `/verify-tamper` `/send` | 挑战/拒绝/只读校验/发送 |
| GET | `/api/device`；POST `/api/device/challenges/:id/decide` `/expire` `/tamper`；`/api/device/replay` | 虚拟设备 |
| GET | `/api/governance`；POST `/api/governance/review` `/audit-tamper-demo` | 治理 |
| GET | `/api/audit`；GET `/api/report` | 审计分页；治理报告 HTML |
| POST | `/api/mode` | 切换自动模式：`manual` / `auto-safe` / `auto-full` |
| POST | `/api/reset` | 重建工作区 |

统一响应 `{ok:true,...}` / `{ok:false,error:{code,message,detail}}`；域错误 200，坏 JSON 400，未知 404。
安全头：CSP（同源脚本/样式）、`nosniff`、`X-Frame-Options: DENY`；静态路径规范化，拒绝 `..`/空字节/反斜杠；body 上限 1 MiB。

## 5. 演示脚本（建议顺序）

1. **工作台**：看统计卡与最近事件。
2. **纪要中心**：对 M2 点"整理纪要" → 读取/摘要/内网发送 → 策略自动确认。
3. **邮件**：选"外发" → 生成冻结操作 → 跳设备页。
4. **设备**：发起挑战 → OLED 显示摘要/哈希/倒计时 → 确认 → 操作 executed/发送 sent。
5. **审批与确认**：查看冻结记录/哈希/事件链；对同一操作"只读篡改校验"；重放旧决定 → `STATE`。
6. **命令台**：依次跑注入/私人邮箱/批量删除/上传/绕过审批样例；看闸门芯片与原始输出。
7. **治理审计**：风险冻结 → 复核 clear；双链校验；篡改链演示；打开治理报告；重置。

> 攻击样例会累积风险分，几次后自动冻结；这是特性，不是故障。用治理页"复核 clear"或"重置演示"恢复。

## 自动模式（可选）

顶栏"模式"三档：

| 模式 | 行为 | 用途 |
|---|---|---|
| `manual`（默认） | 内网邮件策略自动确认；外发/删除/打印/设备 frozen → WS63 | 正常演示，物理锚点 |
| `auto-safe` | 仅 `partner-example.com` 的公开/内部级外发自动确认（配额 3 次）；其他高危仍 WS63 | 低风险自动化 |
| `auto-full` | 所有转交动作自动批准，绕过设备确认；风险冻结仍然生效 | 反面对照，红色警告 |

- 自动批准写 `confirmationId='auto-safe' / 'auto-full'`，审计记 `自动批准`；审批页显示"低风险自动批准 / 全自动批准（未按键）"。
- **auto-full 不是项目定位**：它会绕过物理锚点，只用于演示"全自动为什么会出事"。
- 对照脚本：切到 `auto-full` 跑"攻击：绕过审批话术" → 外发直接执行；切回 `manual` 再跑 → 停在设备确认。
- API：`POST /api/mode {mode}`；`GET /api/state` 返回 `autoMode` / `autoSafe`。

## 7. 边界

- **演示级最小套件**：业务动作模拟（MockLLM + scenario + FakeMailer/假执行器），不接真实邮件/打印/门锁。
- **WS63 是虚拟设备**：真实 SFC1 帧 / HMAC，但没有 SLE/串口/按键/OLED；真板仍停在 M0。
- 无登录/多用户/权限后台；仅监听 localhost。
- `:memory:` 存储，重启清空；报告即时生成，不落盘。
- 运行时的上传/共享等未转交动作仍走内置模拟闸4；只有转交集合走 WS63。
- `auto-full` 自动模式会绕过设备确认，只用于对照演示，不是项目定位；风险冻结仍然生效。
- 不提供距离证明、本人身份认证或防中继；密钥在内存。
