## 1. 发件别名 + 签名（v0.45）

### 配置

`SAFE_OFFICE_SMTP_ACCOUNTS` 的每个账号新增三个可选字段：

```json
{
  "name": "work",
  "from": "you@example.com",
  "fromName": "张工",
  "aliases": [
    { "address": "notice@example.com", "name": "通知" },
    "sales@example.com"
  ],
  "signature": "安全智慧办公\n张工 · 内线 8001"
}
```

- `aliases`：必须是该 SMTP 账号在服务商侧已开通的「发件别名」，否则服务端会拒发；地址小写化、去重，含 CR/LF/尖括号一律拒绝
- `fromName`：`From: "张工" <you@example.com>` 的显示名
- `signature`：纯文本，最多 1000 字符，拒绝控制字符；空行/制表保留

### 行为

- 命令新增可选 `mailAlias`，必须是所选账号（未选则默认账号）已配置的别名；选错直接 400
- **签名在冻结时追加进正文**（`正文\n\n-- \n签名`），因此进入 `bodyHash` / `operationHash`——确认的就是最终发出去的内容，不是发送时才拼
- `mailAlias` 与 `mailAccount` 一样**绑进哈希**（空值不写入，兼容旧记录）；草稿编辑保留别名
- 发送前 `MailerPool` 再校验一次别名归属；`SMTPMailer` 只接受本账号配置的别名
- 列表接口不回传密码，也不回传签名正文，只给 `hasSignature`

### 边界

- 别名能否真正发出取决于邮箱服务商；服务端拒绝会按 `rejected` 落 `failed`，不会自动重试
- 签名是明文随邮件发出，不要放密码/密钥

## 2. 真实自动回信（v0.46）

### 开关与配置（默认关闭，fail-closed）

```bash
SAFE_OFFICE_AUTOREPLY=1
SAFE_OFFICE_AUTOREPLY_ALLOW_TO=alice@partner-example.com,@trusted.example
# 可选
SAFE_OFFICE_AUTOREPLY_ACCOUNT=work
SAFE_OFFICE_AUTOREPLY_MAX_PER_HOUR=5
SAFE_OFFICE_AUTOREPLY_SENDER_HOURS=24
SAFE_OFFICE_AUTOREPLY_MAX_AGE_HOURS=24
SAFE_OFFICE_AUTOREPLY_MAX=10
SAFE_OFFICE_AUTOREPLY_POLL_MS=300000
SAFE_OFFICE_AUTOREPLY_SUBJECT=自动回复：已收到您的来信
SAFE_OFFICE_AUTOREPLY_TEMPLATE=您好，\n\n已收到您的来信，我们会在工作时间内尽快处理。
```

- 开启但白名单为空 → 启动时明确报错，不静默跑
- 白名单支持精确地址或 `@域名`（域名必须以 `@` 开头）
- 演示包强制关闭自动回信

### 安全边界（任何一条不满足就跳过）

| 条件 | 说明 |
|---|---|
| 发件人在白名单 | 否则 `sender-not-allowed` |
| 不是自己 | 与所有发件账号的 from/别名/user 比对 |
| 不是自动回复 | `Auto-Submitted` 非 `no` → 跳过 |
| 不是邮件列表/批量 | `List-Id` / `List-Unsubscribe` / `Precedence: bulk/list/junk` |
| 不是机器地址 | `no-reply` / `mailer-daemon` / `postmaster` 等本地部分 |
| 有 Message-ID | **只认 Message-ID 去重**，UID 变化不可靠时宁可不回 |
| 最近 24h 内 | 首次开启不会把历史邮件全部回一遍；未来时间也跳过 |
| 同一 Message-ID 未回过 | 占位表 `auto_replies` 原子插入，重启/并发都不重复 |
| 同一发件人 24h 内未回过 | 逐发件人限速 |
| 全局每小时有配额 | 默认 5 封 |

- **模板与主题固定，不读取来信主题/正文**：不可信输入不会进入外发内容；回信正文只追加发件账号签名
- 仍走同一闭环：冻结 → `policy-auto-reply` 自动确认 → outbox → 发送；失败/`unknown` **不自动重试**
- 收件人仍受 `SAFE_OFFICE_MAIL_ALLOW_TO` 约束（**双重白名单**，SMTP 层再拒绝一次）
- 每次回信、扫描、失败都写审计链；去重/限速记录落 SQLite，重启不丢

### 触发方式

- 定时轮询（默认 5 分钟，最小 60 秒），启动后立即跑一次
- 邮件页 / 治理页「按策略自动回信」手动触发（审计员/管理员）
- `GET /api/mail/auto-reply` 状态、`POST /api/mail/auto-reply/scan` 扫描

### 边界（材料必须如实写）

- 自动回信**绕过了 WS63 确认**，这是配置层预先授权的策略，不是设备确认；报告里要单列
- 只处理最近 50 封、只扫描一次收件箱文件夹；不做 IMAP IDLE
- 不解析/不回复来信内容，不判断语义；只按白名单与协议头过滤
- SMTP 结果未知时无法保证对方只收到一次（与现有发送闭环相同）

## 3. 审计快照外部存储（v0.47）

```bash
SAFE_OFFICE_AUDIT_EXTERNAL_DIR=E:/audit-offsite
```

- 治理页「导出外部快照」：把当前审计链（`.jsonl` + `.head` + `.tenants`）与本地归档复制成
  `snapshot-<时间>/`，并写 `manifest.json`（每个文件的相对路径、大小、sha256 + 导出时检查点）
- 「校验外部快照」：重算最新快照所有文件，报告缺失/大小不一致/哈希不一致/路径越界
- API：`POST /api/audit/export`（管理员）、`GET /api/audit/external`（审计员）、`POST /api/audit/external/verify`
- 外部目录与本地归档目录互相包含时拒绝导出，避免递归复制
- manifest 最后写且原子替换；中途失败不会留下"看起来完整"的清单

### 边界（必须如实写）

- 只做**本地文件复制**（另一块盘 / 挂载的网络共享），不接 S3/对象存储
- 清单只证明「副本与导出时一致」；有写权限的人可以同时改文件和清单。
  **防篡改仍以本地独立检查点 + 审计链为准**，外部快照是备份/取证副本，不是防篡改介质
- 导出动作本身会追加一条审计，因此在快照之后；快照记录的是导出前的检查点
- 快照不会自动清理，需要时手工轮转外部目录
