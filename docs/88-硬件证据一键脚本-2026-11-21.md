# 硬件证据一键脚本（2026-11-21）

> 目的：把 [85 国奖证据准备](85-国奖证据准备-2026-11-19.md) §3.2 的量化矩阵
> （批准 / 取消 / 超时 / 断链 / 篡改 / 重放 / 时延）做成一条命令，
> 输出可回放的 `rounds.jsonl` + `summary.json` + `summary.md` + `transcript.log`。
>
> **状态：脚本与单测已完成；尚未接真板跑。** 真机结果出来前，材料不能写“已完成”。

## 1. 用法

```bash
cd prototype
# 先看矩阵（不接板）
npm run evidence:run -- --plan

# 双板：执行端 A(COM12) + 确认端 B(COM11)
npm run evidence:run -- --port COM12 --confirm-port COM11 \
  --device ws63-B --actuator-device ws63-A --pin 12
```

- `--port`：执行端 A 的串口（挑战经 A 的 SLE 中继到 B；确认后 A 执行 IO12）。
- `--confirm-port`：确认端 B 的串口（篡改/重放直接打 B；省略时与 `--port` 相同）。
- `--device`：确认端标签（默认 `ws63-B`）；`--actuator-device`：执行端标签（默认 `ws63-A`）。
- `--approve/--cancel/--timeout/--tamper/--replay/--disconnect`：覆盖轮数（默认 20/5/5/3/3/3）。
- `--only=approve,cancel`：只跑部分阶段；`--yes`：跳过开始前的回车确认。

## 2. 矩阵与判定

| 阶段 | 默认轮数 | 操作 | 通过标准 |
|---|---:|---|---|
| approve | 20 | B 板**短按** KEY2（<600ms） | `decision=1` 且 A 回 `status=0 pin=12 level=1` |
| cancel | 5 | B 板**长按** KEY2 | `DECISION`，且没有执行帧 |
| timeout | 5 | 不按键（5s TTL / 8s 超时） | `TIMEOUT`，且没有执行帧 |
| disconnect | 3 | 挑战发出后按 B 板 KEY1 复位 | `TIMEOUT`（fail-closed），且没有执行帧 |
| tamper | 3 | 自动（改 MAC 帧打 B） | 被拒（`BAD_MAC`） |
| replay | 3 | 自动（过期帧重放打 B） | 被拒（`REPLAY`） |

- 批准项对外按前 **10 轮**计（20 轮全部用于时延采样，多跑不亏）。
- 时延口径：**挑战发出 → ACK**，包含人工反应时间；同时记录进程总耗时。
- 每轮出现执行帧后自动补发 `level=0` 复位，避免继电器/锁体长期通电。

## 3. 输出

`prototype/out/hardware-evidence-<时间戳>/`

| 文件 | 内容 |
|---|---|
| `rounds.jsonl` | 每轮一行：阶段、序号、通过、退出码、解析结果、时延、输出尾部 |
| `summary.json` | 各阶段通过率、批准前 10 轮口径、时延 P50/P95、全部明细 |
| `summary.md` | 一页摘要（可直接贴进材料） |
| `transcript.log` | 带时间戳的人机操作记录（含提示语） |

## 4. 边界（必须与结果一起写）

- **ACK ≠ 开锁**：只证明“板端执行帧 → 执行端 ACK”；锁舌动作需人工目视并单独记录。
- **不装续流二极管**（2026-11-21 拍板）：感性反电动势无抑制，属演示级残余风险。
- 锁体由**板载 5V/USB** 驱动；不接市电、无保险丝；不宣称门禁认证/可靠开锁/距离证明。
- 篡改/重放直接打确认端 B（不经中继）；星闪中继链路的异常路径仍由 `sfc1:neg` 与 docs/74 覆盖。
- 时延含人工反应，不是纯系统时延；报告里必须写明。
- 本脚本不录视频；视频需另拍（B 屏 → 按键 → 吸合 → 锁舌 → 回执）。
