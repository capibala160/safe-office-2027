## 7. 对外口径（能说 / 不能说）

**能说**

- 632 项测试（630 通过 + 2 跳过）+ 12 项 E2E 全绿（本地实测）。
- 设备联动：确认通过后 WS63 真板验签执行 GPIO（IO13 LED / IO10 蜂鸣器），回 ACK 并写「设备执行」审计。
- 屏幕共享：控制台 `getDisplayMedia` 真实投屏，服务端只记录开始/结束、目标与 surface（画面不上传服务器）；2026-11-04 已用 Edge 实机点击验证（`npm run share:check`）。
- 录音转写：腾讯云一句话识别已接通（真实音频返回文本，requestId 可查）；**音频会出端，只处理「公开」级**，转写文本一律过闸1。
- 真实模型 3 轮：**本轮 20 条验证攻击样本 ×3 轮 = 60 次运行未得逞**（8 条每轮都被拦、12 条模型未尝试）；正常 17/18；误拦 0。
- 单层消融：闸4 是当前语料下唯一不可替代的层。
- 单板闭环：批准/取消、6 类异常、M4 连跑、M1 掉电保存全部真板通过。
- 双板 SLE 链路：两块 WS63 真板配对（MTU 251）后双向心跳 `ALIVE`，KEY1 复位触发的断线在
  3500ms 超时后自动恢复（`up=2 down=1 timeout=1`，`bad=0 send_fail=0`）；**只证明链路存活，
  不承载业务帧**（2026-11-16，见 [73](73-M2双板SLE准备-2026-11-14.md) §10）。
- 业务帧上 SLE（M3'）：PC 只接 A 的串口，挑战经 SLE 到 B、B 按键后决策原路回 PC，
  批准/取消均真机通过；A 不持钥，验签与绑定仍在 PC/B 两端完成（[74](74-M3prime-业务帧上SLE-2026-11-16.md)）。
- 双板执行闭环：确认用 B 的钥匙、执行用 A 的钥匙，A 验签后驱动 IO12（level=1/0）并回 ACK；
  两板 `device_id` 已区分（ws63-A / ws63-B）。
- 配网与探活走 SLE：PC 只接 A 的口即可给 B 配网、发 PING 验钥匙；B 的串口不参与
  （配对码看 OLED）。A 重烧后需先直连配网。
- 双板短时稳定：30 分钟心跳 + 每 5 分钟 PING（本地/中继）共 6 轮，零坏帧、零新增超时，
  12/12 PING 通过（**只能写短时稳定，不能写 >1h**）。
- WiFi 扫描与 SLE 共存：30 分钟内 WiFi 每 10 秒扫描（`ret=0`）持续成功，SLE 心跳零坏帧、
  零超时，PING 本地/中继全过（**只覆盖扫描态，不连 AP、无数据业务**）。
- 跨步骤来源追踪：摘要/OCR/转写/生成稿继承来源闭包；出站与打印按闭包核对——
  来源未授权、来源受污染、转换降级都会被拒（4 条测试 + 全量 618 全绿）。
- 附件来源闭包：上传附件按内容对上已知文档后继承密级/污点；机密、污点、
  内部级外发在冻结与发送前两处拒绝（6 条测试）。
- 硬件结构化摘要：挑战帧 v2 携带收件人/密级/附件数，板端按字段分 3 页轮播；
  真机批准/取消/执行通过，**操作者已肉眼确认三页内容正确**（TO/LEVEL/ATTACH/HASH）。
- 委托只能收窄：子委托的动作、有效期、范围标签都必须是父令牌的子集，且**执行期再复核一次**（8 条测试）；
  顶层签发行为不变。
- 任务证据回放：按 `runId` 返回「要求→计划/批准→闸与风险→实际调用→回执」时间线，
  并给出审计链与冻结记录校验结论；控制台已有「任务回放」页面（1 条 E2E）。
- 一机一钥方案 A、控制台闸4接真板，均真板验证。
- CalDAV 真写入：服务器返回 201（**只证明服务器接受，不证明手机已同步**）。

**不能说**

- 「A 是保密中继」——A 不持钥、无法伪造决策，但 CHALLENGE 摘要明文经过 A，中继方可读摘要。
- 「配网/探活也走 SLE」——A 已配网后可以中继；A 自己重烧后仍需直连 UART 配网。
- 「WiFi 与 SLE 共存稳定」——只有 30 分钟、扫描态（不连 AP、无数据业务）的数据；
  >1h 与 WiFi 数据业务共存未测。
- 「所有分步泄露都能识别」——闭包覆盖 Agent 派生条目与可文本匹配的附件；
  跨 Agent 委托链、二进制附件内容、少于 12 字的片段、未入库的同内容文件都不在覆盖范围。
- 「屏幕能显示所有情况」——三页已在一个场景（ASCII 收件人、内部级、0 附件）人工确认；
  中文收件人（显示为 ?）、多附件、超长摘要的分页表现未逐一验证。
- 「委托授权全生命周期可控」——签发收窄与执行期复核已做；`scope` 仍是声明式标签，执行时不与操作比对。
- 「回放能逐字重放」——页面有时间线，但计划原文、板端原始确认帧不落库，不能逐字重放；
  导出/PDF 未做。
- 「双板链路有身份认证」——心跳未认证，SLE 本地地址是演示固定值，见 docs/73 §8。
- 「eFuse 能防物理提取」——eFuse 无读保护；已写入的 KEK 只能防外部 Flash dump，
  能执行代码仍可读出。
- 「手机日历已同步」——DAVx⁵ 在鸿蒙机上 `-1` 未入库，真 Android 尚未复测。
- 「真实门锁已联动」——设备执行已支持 IO12 继电器并真机验证翻转，但**没有继电器/锁体实物**，不上锁具就不算开锁。
- 「能证明本人在场」——SFC1 是对称 PSK，只能证明"持有该密钥的设备"。
- 「真实世界攻击成功率 0%」——应说"本轮 20 条验证集攻击样本、3 轮共 60 次运行未得逞；
  端到端 95% 上界约 13.9%，但模型实际尝试的 8 条条件上界仍约 31%"，见 [69](69-评测口径与统计边界-2026-11-05.md)。
- 「GitHub Actions 全绿」——以 Actions 页最新 run 为准；本地 `npm run ci` 是权威口径。GitCode 流水线已取消。
