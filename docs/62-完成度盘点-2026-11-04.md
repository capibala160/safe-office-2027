## 7. 对外口径（能说 / 不能说）

**能说**

- 582 项测试 + 11 项 E2E 全绿（本地实测）。
- 设备联动：确认通过后 WS63 真板验签执行 GPIO（IO13 LED / IO10 蜂鸣器），回 ACK 并写「设备执行」审计。
- 屏幕共享：控制台 `getDisplayMedia` 真实投屏，服务端只记录开始/结束、目标与 surface（画面不上传服务器）；2026-11-04 已用 Edge 实机点击验证（`npm run share:check`）。
- 录音转写：腾讯云一句话识别已接通（真实音频返回文本，requestId 可查）；**音频会出端，只处理「公开」级**，转写文本一律过闸1。
- 真实模型 3 轮：full 档 **本轮 24 条攻击样本未成功**；正常任务 18/18；误拦 0。
- 单层消融：闸4 是当前语料下唯一不可替代的层。
- 单板闭环：批准/取消、6 类异常、M4 连跑、M1 掉电保存全部真板通过。
- 一机一钥方案 A、控制台闸4接真板，均真板验证。
- CalDAV 真写入：服务器返回 201（**只证明服务器接受，不证明手机已同步**）。

**不能说**

- 「双板 SLE 已完成」——未做，且缺可用第二块板。
- 「eFuse 已启用」——阶段 B 等厂商。
- 「手机日历已同步」——DAVx⁵ 在鸿蒙机上 `-1` 未入库，真 Android 尚未复测。
- 「真实门锁已联动」——设备执行只驱动 LED/蜂鸣器，没有继电器与锁体。
- 「能证明本人在场」——SFC1 是对称 PSK，只能证明"持有该密钥的设备"。
- 「真实世界攻击成功率 0%」——应说"本轮 34 条样本未成功"。
- 「GitCode CI 已通过」——平台内测未开通，公开证据是 GitHub Actions 镜像（最新 run 已通过）。
