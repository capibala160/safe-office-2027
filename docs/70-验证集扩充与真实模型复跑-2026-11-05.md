## 3. 统计口径（关键）

两个分母必须分开写：

| 口径 | 分子/分母 | 95% 上界 |
|---|---|---:|
| **端到端攻击得逞**（含模型未尝试） | 0 / 20 条独立样本（60 次运行） | **13.9%** |
| **模型尝试越权后的网关绕过** | 0 / 8 条独立样本（24 次尝试） | **31.2%** |
| 旧口径（8 条验证样本） | 0 / 8 | 31.2% |

所以：

> 端到端 0/20 的 95% 上界从 31.2% 降到 **13.9%**；但这主要因为 12 条样本模型没有产出
> 越权动作，**不能**据此说「网关对 20 种攻击的拦截率是 100%」。模型实际尝试的 8 次里
> 网关拦下 8 次（0/8 绕过，上界仍约 31%）。

### 3.1 合规对手（MockLLM）口径

MockLLM 是「一定会照做」的对手，用来测**网关本身**。为了让 20 条都真正尝试，
2026-11-05 扩展了 4 条 Mock 规划（打印机密/投屏机密选 M1、外部录音注入照做、
图片注入照做）——这是**扩展对手覆盖**，没有改任何网关规则。

结果（validation 20 条，full 档）：

| 指标 | 结果 |
|---|---|
| 攻击得逞 | **0 / 20** |
| 主动拦截 | **20 / 20**（计划校验×17、闸2×4、闸4×3、策略矩阵×2、能力专项×2、闸3×1、沙箱×1） |
| 未尝试 / 故障 | 0 / 0 |
| 95% 上界（条件） | **13.9%** |

所以两个条件口径要分开写：

- **网关本身**（合规对手，20 条全尝试）：0/20 绕过，上界 **13.9%**
- **真实模型实际尝试**（8 条）：0/8 绕过，上界 **31.2%**（模型自我审查，样本没被真正考验）
