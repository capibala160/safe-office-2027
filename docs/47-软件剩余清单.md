# 软件剩余清单（2026-10-31 · v0.41.0 时点；2026-11-02 更新真实模型 ×3 结果）

> 本文是软件侧"还差什么"的完整盘点，供 4C 2027 / 毕设 / 演示验收排期用。
> 硬件阻塞项单列在 §6；不依赖硬件的项按优先级给出建议。
> 状态随版本更新，完成一项就把对应行改成 ✅ 并注明版本。

## 1. 业务动作仍是模拟

| 项 | 现状 | 真实化需要 | 建议 |
|---|---|---|---|
| 屏幕共享 `shareScreen` | 只输出"已开启" | WebRTC / 局域网投屏 | **保持模拟**（工程量与演示收益不匹配） |
| 录音转写 `transcribeAudio` | 返回模拟文本 | 云端 ASR（key）或本地 Whisper（模型/算力） | **保持模拟**，除非拿到 ASR 服务 |
| 日历预约 | 已真写 `.ics`（v0.37），未导入日历账户 | CalDAV / OAuth 接入 | P3，收益有限 |
| 打印 | 纯文本 A4 PDF（v0.40），可选 `PrintTo` | 富文本/表格排版 | P3 |
| 文档共享 | ✅ v0.41 已真实化 | — | — |

## 2. 邮件只做了半程

| 项 | 现状 | 建议 |
|---|---|---|
| 收件箱同步 / 自动回信 | 未做；IMAP 只轮询退信 | P2（做之前先想清楚"Agent 读信"的安全边界） |
| 多发件账号 / 别名 | 未做，单 SMTP 账号 | P3 |
| POP3 | 未做 | 不做（IMAP 已覆盖） |
| 退信 7 天窗口外 | 已读且超过 7 天的退信需手工导入 `.eml` | 已知边界，可接受 |

## 3. 部署与运维（目前只有"本机演示"形态）

| 项 | 现状 | 建议 |
|---|---|---|
| HTTPS / 反向代理 / Docker | 无；只监听 127.0.0.1，`--lan` 只开放确认页 | **P1：一键演示包**（种子数据 + 演示账号 + 一条命令）优先于容器化 |
| 审计归档 / 轮转 / 保留策略 | 有 JSONL 增量 + HMAC 检查点，无归档清理 | P2 |
| 监控告警 | 无，治理页靠人看 | P3 |

## 4. 账号与数据治理

| 项 | 现状 | 建议 |
|---|---|---|
| 禁用 / 删除账号 | 只能改密、管理员重置、TOTP | **P2：禁用账号**（删除可后置） |
| 审计分链 | 全局单链，未按租户分链 | P2（与多租户叙事配套） |
| 附件保留策略 | 有哈希/加密/白名单/ClamAV；编辑/驳回会清孤儿，无保留期限 | P3 |
| 租户模型 | 租户 = 登录用户名，不是组织/企业 | 已知边界，材料里如实写 |

## 6. 硬件阻塞项（不属于软件排期）

- WS63：M1 Flash 掉电保存 → M2 双板 SLE 心跳/重连（`init_sle_mac failed` 待查）→ M3 SFC1 上板（UART + OLED + KEY2 + mbedTLS HMAC）→ M4 连跑验收
- PC 侧 `SerialTransport` 只到切帧，未接真 COM
- 设备/门锁真实控制
- 当前阻塞：板子未插，本机无 COM11 / CH340

## 7. 建议顺序（不依赖硬件）

1. **一键演示包**——种子数据 + 演示账号 + 单条命令启动，答辩/验收即开即用；
2. **账号禁用 + 审计按租户分链**——补齐账号治理与多租户叙事；
3. 其余按 P2/P3 视时间推进；屏幕共享/转写继续如实标"模拟"。

已完成：V-A2 个人域拒绝（v0.42，见 [48](48-真实模型三轮复跑-2026-11-02.md) §6.5）。
