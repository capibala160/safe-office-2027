## 2. 邮件只做了半程

| 项 | 现状 | 建议 |
|---|---|---|
| 收件箱同步 / 自动回信 | ✅ v0.43 只读同步：先读 `bodyStructure`，只下载选中 text/plain（或 text/html）段 ≤256KB；`download()` 已解码，不再二次解码；跳过附件整棵子树；超时先强制 close 再重试；并发按 `limit` 区分；不标已读、不执行邮件内容；自动回信仍未做 | 自动回信 P3（先定"Agent 读信"安全边界） |
| 多发件账号 / 别名 | ✅ v0.43 `MailerPool`（`SAFE_OFFICE_SMTP_ACCOUNTS` JSON）；`operation.mailAccount` 已贯通命令→冻结→SQLite→审批展示，并进入 `operationHash`；**默认账号在冻结时解析并固化**，发送时不再读当前默认值；列表不回传密码 | 控制台暂未暴露逐次账号选择（缺省用冻结时默认账号）；别名/签名 P3 |
| POP3 | 未做 | 不做（IMAP 已覆盖） |
| 退信 7 天窗口外 | 已读且超过 7 天的退信需手工导入 `.eml` | 已知边界，可接受 |
