## 6. 硬件阻塞项（不属于软件排期）

- WS63：M1 Flash 掉电保存 → M2 双板 SLE 心跳/重连（`init_sle_mac failed` 待查）→ M3 SFC1 上板（UART + OLED + KEY2 + mbedTLS HMAC）→ M4 连跑验收
- PC 侧 `SerialTransport` 已支持真 COM 打开（`openSerialPort`，serialport 可选依赖）+ 切帧/超时/串行化；**未在真板验证**，板子到位后用 `--port COM11` 接入
- 设备/门锁真实控制
- 硬件进展（2026-11-04 晚）：**M3 真机通过**——换板后一次烧录成功，批准/取消闭环都跑通，见 [57](57-M3板端SFC1与串口CLI-2026-11-04.md) §6。**已完成**：6 类异常全部上板（§6.5）、M1 掉电保存（§6.7）、M4 十连跑（§6.6）、一机一钥方案 A（[60](60-一机一钥与安全存储-设计-2026-11-04.md)）。**剩余硬件项**：M2 双板 SLE 心跳/断线重连（第一块板芯片被锁，能否解锁待厂商确认，见 [10](10-硬件上手记录.md) §7）、eFuse 阶段 B（等厂商）。诊断/报修流程见 [58](58-WS63不上电诊断清单-2026-11-04.md)；监听工具 `npm run serial:probe`（**固件只在启动瞬间打印，必须先开监听再复位**，否则必然 0 字节）
