## 2. CI 矩阵 + 覆盖率

`.github/workflows/ci.yml` 重写为 4 个 job：

| job | 内容 |
|---|---|
| `test` | **ubuntu + windows** 矩阵（Node 24）；Linux 跑 `node --test --experimental-test-coverage` 并上传 `coverage.txt`；Windows 跑 `npm test` |
| `quality` | lint + typecheck + strict + Playwright E2E |
| `audit` | `npm run audit`（高危阻断） |
| `docker` | 构建镜像 → 起容器 → 轮询 `/api/health` → 失败打印日志 |

> **为什么不是 Node 20/22/24**：项目依赖 `node:sqlite`，Node 20/22 不支持（22 早期还需 flag）。
> 用 **OS 矩阵**（Linux + Windows）证明可移植性更真实——本机就是 Windows。

覆盖率：使用 Node 24 内置 `--experimental-test-coverage`，不引入新依赖；
当前全量行覆盖约 **48%**（`runtime.cjs` 51%、`task-replay.cjs` 95%、`ws63-protocol.cjs` 12%——
后者主要靠 C 侧跨语言测试覆盖，Node 覆盖率低属预期）。
