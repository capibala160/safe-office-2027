# CI 与本地一键验证（v0.45 更新）

> 之前 346 项测试 + 7 项 E2E 全靠手跑，没有可复现的执行入口。
> 本轮补两样：**本地一键 `npm run ci`** + **可移植的 GitHub Actions 定义**。

## 1. 本地一键

```bash
cd prototype
npm run ci        # = lint && typecheck && typecheck:strict && npm test && E2E
```

- lint：**真实 ESLint（flat config + eslint-plugin-security）+ 自定义危险模式扫描**；当前 0 error / 0 warning。
- typecheck：`tsc -p tsconfig.json`（模块解析）；`typecheck:strict` 开启 `strict: true` + checkJs，覆盖
  `src/faults.cjs`、`src/operation.cjs`、`src/audit-sign.cjs`、`src/ws63-protocol.cjs`
  （以及它们依赖的 `src/governance.cjs`）——冻结操作、检查点签名、SFC1 编解码。
- 单元/集成：`node --test`（按测试文件并行）。历史上因“bad port”偶发串行过；
  补了统一端口重试、测试改用 port 0 / 独立临时目录后，连续 3 次并行全绿，耗时从 ~20s 降到 ~4s。
- 浏览器 E2E：`node --test e2e/ui.e2e.cjs`；优先用本机 Edge，没有则回退 Playwright 自带 Chromium。
- 任一步失败即非 0 退出，适合挂到任何调度器/脚本里。

单独跑也行：`npm test` / `npm run e2e`。

## 3. 这条 CI 覆盖什么 / 不覆盖什么

**覆盖**

- 五道闸、策略与权限、令牌/委托、沙箱、审计链与检查点、租户隔离；
- 确认执行闭环（含 unknown 不重试）、退信 DSN、MCP 注册、日历 .ics；
- HTTP 接口权限、登录/2FA/改密、上传、退信、MCP、手机确认、虚拟设备确认（E2E）。

**不覆盖（环境依赖，故意跳过或 Mock）**

- ClamAV 真实扫描：未配置 `SAFE_OFFICE_CLAMAV_CMD` 时 1 项跳过（CI 无病毒库）；
- 真实 SMTP / 真实打印 / 系统日历：测试用 FakeMailer、模拟打印器、临时目录；
- 真实模型：评测 `eval/` 不进球型 CI（需要 key 与外部网络）；
- WS63 硬件：无串口/E2E 依赖虚拟设备。

这些项的验证方式见 `docs/35`（ClamAV 实测）、`docs/22`（SMTP 实测）、
`docs/38`（日历落盘）、`docs/21`（硬件四阶段）。

## 4. 边界

- 覆盖率：CI 用 Node 24 内置 `--experimental-test-coverage`（**2026-11-19 实测：行 88.12% / 分支 75.59% / 函数 88.74%**，只含单测/集成、不含 E2E）。可写「行覆盖约 88%」，但**不能写「100%/生产级覆盖率」或把覆盖率当作测试充分性的证明**。`typecheck:strict` 覆盖 52 个仓内文件（51 .cjs + 1 .d.ts，`tsconfig.strict.json`），但仍不是全仓。
- 测试并行依赖每个测试文件自己隔离端口/临时目录；新增测试若使用固定端口或共享文件，必须改回隔离写法。
- GitCode 流水线已取消（平台 404）；GitHub Actions 是唯一远端 CI。**本地 `npm run ci` 仍是权威口径**，远端结果作为补充证据。
- 发布包不进 CI：`npm run release` 生成 `dist/*.tar.gz + sha256 + MANIFEST`（**2026-11-19 按 HEAD 重打：约 4.27MB / 331 文件**；2026-11-17 首包为 4.25MB / 330 文件）。
- E2E 依赖浏览器二进制，首次运行需 `npx playwright install chromium`（本机已用 Edge 可跳过）。
