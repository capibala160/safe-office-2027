# CI 与本地一键验证（v0.40）

> 之前 346 项测试 + 7 项 E2E 全靠手跑，没有可复现的执行入口。
> 本轮补两样：**本地一键 `npm run ci`** + **可移植的 GitHub Actions 定义**。

## 1. 本地一键

```bash
cd prototype
npm run ci        # = node --test && node --test e2e/ui.e2e.cjs
```

- 单元/集成：`node --test`（默认发现 `test/*.test.cjs`）。
- 浏览器 E2E：`node --test e2e/ui.e2e.cjs`；优先用本机 Edge，没有则回退 Playwright 自带 Chromium。
- 任一步失败即非 0 退出，适合挂到任何调度器/脚本里。

单独跑也行：`npm test` / `npm run e2e`。

## 2. GitHub Actions 定义

`.github/workflows/ci.yml`：push / PR 触发，Ubuntu + Node 24，`npm ci` →
`npx playwright install --with-deps chromium` → `npm test` → `npm run e2e`；
失败时把 `prototype/out` 作为 artifact 上传。

**注意**：仓库主地址在 **gitcode**（`Yqx200476/safe-office-2027`），GitHub Actions
不会在 gitcode 上自动执行。这份定义是可移植配置：
- 镜像到 GitHub 仓库 → 直接生效；
- 若 GitCode 流水线支持 GitHub Actions 语法 → 可直接复用；
- 不接任何平台时 → 用本地 `npm run ci`，口径完全一致。

## 3. 这条 CI 覆盖什么 / 不覆盖什么

**覆盖**

- 五道闸、策略与权限、令牌/委托、沙箱、审计链与检查点、租户隔离；
- 确认执行闭环（含 unknown 不重试）、退信 DSN、MCP 注册、日历 .ics；
- HTTP 接口权限、登录/2FA/改密、上传、退信、MCP、手机确认、虚拟设备确认（E2E）。

**不覆盖（环境依赖，故意跳过或 Mock）**

- ClamAV 真实扫描：未配置 `SAFE_OFFICE_CLAMAV_CMD` 时 1 项跳过（CI 无病毒库）；
- 真实 SMTP / 真实打印 / 系统日历：测试用 FakeMailer、模拟打印器、临时目录；
- 真实模型：评测 `eval/` 不进球型 CI（需要 key 与外部网络）；
- WS63 硬件：无串口/E2E 依赖虚拟设备。

这些项的验证方式见 `docs/35`（ClamAV 实测）、`docs/22`（SMTP 实测）、
`docs/38`（日历落盘）、`docs/21`（硬件四阶段）。

## 4. 边界

- 没有覆盖率统计、没有 lint/类型检查（纯 CJS 项目，未引 ESLint/TS）。
- 工作流只在 Ubuntu 验证；Windows 本机用 `npm run ci`，两者测试口径一致。
- 不自动发布/打包；CI 只证明"测试通过"，不产出可分发物。
- E2E 依赖浏览器二进制，首次运行需 `npx playwright install chromium`（本机已用 Edge 可跳过）。
