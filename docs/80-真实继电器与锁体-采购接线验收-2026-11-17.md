# 真实继电器 / 锁体：采购、接线与验收（2026-11-17）

> 软件与固件侧已就绪：协议执行帧（0x21）、IO12 驱动、ACK 回执、继电器语义
> （docs/68）都验过。缺的只是**实物**。本页给出「买了就能验」的最小方案。
>
> 边界先说清：这是 **12V 直流演示锁具**，不接市电、不是门禁认证产品；
> 通过验收也只能写「板端引脚 → 继电器 → 锁体动作已验证」，不能写「安全门禁」。

## 1. 采购清单（约 ¥30–60）

| 件 | 规格 | 参考价 | 备注 |
|---|---|---|---|
| 单路继电器模块 | **5V 线圈、光耦隔离、高电平触发** | ¥3–6 | 高电平触发才能匹配固件 `level=1`；买低电平触发则开/关语义相反 |
| 12V 电磁锁（通电开锁） | 小型 solenoid lock，12V/0.5–1A | ¥15–30 | 也可用 12V 磁力锁（注意 fail-safe/fail-secure 语义不同） |
| 12V 直流电源 | ≥1A，带 DC 头 | ¥10–20 | **独立供电**，不要从板子取 |
| 续流二极管 | 1N4007 | ¥0.1 | 并在锁体线圈两端（负极朝电源正） |
| 杜邦线/端子 | 母-母若干 | ¥2 | — |

> 不建议：直接让 GPIO 驱动锁体线圈（电流不够且会损坏芯片）；用 220V 门锁（演示不需要且有安全风险）。

### 1.1 推荐选型（2026-11-17）

**12V 小型电磁柜锁（通电开锁 / 断电上锁，fail-secure）**：

- 搜索词：`12V 电磁柜锁 通电开锁 小型`、`12V 电插锁 fail secure`；
- 规格：12V DC、通电开锁/断电上锁、≤1A、带弹簧复位；
- 与固件语义一致（`unlock` → `level=1` 通电开锁；`lock` → `level=0` 断电上锁）；
- 不建议磁力锁：通电上锁/断电开锁（fail-safe），语义与现有映射相反，且长期通电发热。

演示道具：小木盒/亚克力板做一扇门，柜锁固定在门内侧、锁舌对框；
批准后听到吸合、锁舌缩回、门可开——比裸锁体更有说服力。

### 1.2 已选型号：LY-03A（2026-11-17 确认）

| 参数 | 数值 | 对本项目的影响 |
|---|---|---|
| 电压 | DC 12V | 与方案一致 |
| 电流 | ≈0.8A（部分批次标 0.6–1.15A） | 电源建议 **12V / 2A**（1A 余量偏小） |
| 工作方式 | 通电开锁、断电上锁（fail-secure） | 与固件语义一致：`unlock`=`level 1` |
| 行程 | ≈8mm | 小门/抽屉演示足够 |
| 通电限制 | 建议单次 ≤10s，勿连续通电 | `relay:test --hold` 保持 1000ms 即可，别长时间吸合 |

结论：**可用**。接线按 §2，续流二极管必须有（0.8A 感性负载）；电源换成 12V/2A 更稳。

## 2. 接线（全部断电后操作）

```
WS63 板                        继电器模块（高电平触发）              12V 锁体
┌──────────┐                  ┌────────────────────┐            ┌──────────┐
│ IO12 ────┼─────────────────▶│ IN                 │            │          │
│ GND  ────┼──────────┬──────▶│ GND            COM │───────┐    │ 线圈 +   │
│          │          │       │ VCC ◀── 外部 5V    │       │    │          │
│ 3V3/5V   │          │       │ NO  ───────────────┼───────┼───▶│          │
└──────────┘          │       └────────────────────┘       │    │          │
                      │ 外部 5V GND ───────────────────────┘    │ 线圈 −   │
                      │                                        └────┬─────┘
                      │                                             │
                      └────────────── 外部 12V − ────────────────────┘
外部 12V + ── 保险丝(1A) ── 继电器 COM；继电器 NO ── 锁体 +
锁体线圈两端并 1N4007（负极接 12V +）
```

要点：

1. **共地**：板 GND、外部 5V GND、外部 12V GND 必须接在一起；
2. 继电器模块 VCC 用**外部 5V**（板子 3.3V 不一定带得动线圈）；
3. IO12 只驱动模块 IN（光耦输入，几 mA），不要直连线圈；
4. 锁体线圈并联 1N4007 续流，防反向电动势；
5. 先不接锁，只接继电器，听到“咔哒”再上锁体。

## 3. 软件配置

```bash
# 1) 板端已烧 M3'/v2 固件（IO12 支持），主机配置继电器语义：
export SAFE_OFFICE_ACTUATOR_RELAY_PIN=12     # Windows: set SAFE_OFFICE_ACTUATOR_RELAY_PIN=12

# 2) 一键通断自检（不需要业务语义，直接发执行帧）
cd prototype
npm run relay:test -- --port COM11 --device ws63-A --times 2 --hold 1000
```

期望输出：

```
继电器/锁体自检：ws63-A @ COM11，IO12，2 轮，每轮保持 1000ms
  [1] level=1 → ACK status=0 pin=12 level=1
  [1] level=0 → ACK status=0 pin=12 level=0
  [2] ...
完成：2/2 轮 ACK 通过
```

同时应听到继电器“咔哒”并看到锁体动作。脚本失败也会把锁复位到 `level=0`。

## 4. 业务路径验证（可选，更接近答辩）

门锁类设备名（含「锁/门禁/门」）走 `deviceControl`，操作 `unlock/lock`：

```bash
# 完整双板链路：B 板确认 → A 板验签 → IO12 → 锁体
cd prototype
node serial-confirm.cjs --port COM11 --device ws63-B \
  --to partner@example.com --subject "开锁演示" --ttl 90 --timeout 75000 \
  --actuator-device ws63-A --actuator-pin 12 --actuator-level 1
```

期望：B 屏分页显示摘要 → 短按 KEY2 → A 板继电器吸合 → ACK `status=0`。

## 6. 安全与口径

- **不接市电**、不替代门禁/消防产品；演示级 12V 锁具；
- 断电即失效的语义取决于锁型：solenoid 断电上锁，磁力锁断电开锁（fail-safe）——
  材料里必须写清用的是哪种；
- GPIO/继电器只证明「引脚动作 + 触点闭合」，不证明「真实门被可靠锁住」；
- 长期通电的锁体会发热，演示时保持时间 ≤ 数秒；
- 若后续要接真实门禁，需要独立供电、保险丝、防拆与认证，不在本项目范围。
