## A 标准系统主设备（RK3568 级）

- **选型**：触觉智能 SBC3568 / 润开鸿 DAYU200 类官方标准系统平台（触觉智能为首批适配 OH 6.x 的厂商，RK3566/3568/3588/3576 全家桶）。**下单前问客服**：能否提供「OpenHarmony 6.0 可烧录镜像 + 烧录指引」
- **【等板】烧录**：用厂商镜像 + 瑞芯微烧录工具（Windows 版）；**先烧官方 6.0 镜像跑通，再做应用**
- **【等板】验证里程碑**：① 系统正常启动 ② `hdc list targets` 能看到设备 ③ 装一个 ArkTS 空应用跑起来
- **口径备忘**：主设备版本 = **OpenHarmony 6.0.0.1 Release（标准系统，API 20）**

## B WS63 星闪节点（两条路线，选一）

**源码**：
- 官方仓：`gitee.com/HiSpark/ohos_ws63`（基于 **OpenHarmony 5.1.0 Release** + WS63 SDK 1.10.101 裁减，28+ 示例含 SLE）
- FBB SDK：`gitee.com/HiSpark/fbb_ws63`（配套 HiSpark Studio，支持润和/小熊派多款板）

**路线 1（推荐先试）：Windows + HiSpark Studio（海思 IDE）**
- 安装时**勾选 Python 3.11.4**（用系统 Python 易挂）
- 新建工程时 **SDK 路径必须指到 `fbb_ws63/src` 这一层**（指错=建工程失败）
- 烧录：官方 burntool，**Chip 选 WS63**

**路线 2：WSL / Ubuntu 源码编译**
- `hb build -f` 流程；**已知坑**：
  - demolink 任务堆栈 **1000 → 4000**（不改会崩）
  - 不加 `printf_adapt` **串口无输出**
  - 需按指南改 `BUILD.gn` / `ohos.cmake` / `config.py`（加入 demolink/printf_adapt）
- Linux 烧写用 `xf_burn_tools`
- 速通参考：OpenHarmony 论坛「开箱即用的 WS63/WS63E 编译环境 + 快速烧录工具」帖

**【等板】验证里程碑**：① 点灯 ② 串口 printf ③ BLE 示例 ④ **SLE 示例**（第二块板到货后做**双板握手**）
**⚠️ 版本口径**：节点基线是 OH 5.1.0 轻量系统（还没跟到 6.0）——材料里**分开写**："主设备 OH 6.0.0.1 标准系统 + 星闪节点 OH 轻量系统"
