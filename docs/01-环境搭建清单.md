# 环境搭建清单（P0 → P1 用）

> **2026-10-17 口径变更**：本项目为 **4C 2027 物联网应用类 + 毕设项目，不参加国创赛**。底座默认 **OpenHarmony 4.x/5.x**，6.0.0.1 仅在借到对应板卡时作为可选项。下文“6.0.0.1 镜像”要求只适用于选择 6.0.0.1 路线；4.x/5.x 路线只需**镜像稳定、HUKS 可用、ArkTS 能跑、串口能接 WS63**。主设备本身也是可选项（Node 网关 + WS63 同样成立）。
>
> **v0.6 采购更正**：购买前取得精确的镜像版本、SDK 与构建版本证据，仅有“6.0 镜像”这类模糊说法不足。提前验证 HUKS 实际保护级别、主板到 WS63 的 USB/UART 驱动；无主板 SLE 时采用 WS63 网关与确认节点链路。价格与兼容性仍是候选信息。详见 [落地验收](03-优化记录与落地验收.md)。

> 三条线：**A 标准系统主设备（可选）**｜**B WS63 星闪节点**｜**C 开发机（这台 Windows）**
> 总原则：**能用预编译镜像就不编译源码**——全量编译 OH 源码树要 100GB+ 磁盘和数小时，本机 C 盘紧（F 盘已被游戏占），默认不做；仅当确实需要"系统层改造"才考虑。
> 标注：`【等板】` = 硬件到手后执行；`【随时】` = 现在就能做。

## A 标准系统主设备（RK3568 级，可选）

- **选型**：触觉智能 SBC3568 / 润开鸿 DAYU200 类标准系统平台。**配置（如买）：RK3568 · 4GB RAM + 32GB eMMC**；**优先选厂商 4.x/5.x 稳定镜像**，6.0.0.1 仅在厂商能提供时考虑。**下单前问客服**：镜像精确版本、烧录指引、SDK、4GB 版本是否有对应镜像
- **【等板】烧录**：用厂商镜像 + 瑞芯微烧录工具（Windows 版）；**先烧厂商镜像跑通，再做应用**
- **【等板】验证里程碑**：① 系统正常启动 ② `hdc list targets` 能看到设备 ③ 装一个 ArkTS 空应用跑起来
- **口径备忘**：主设备版本 = **实际镜像版本**（4.x/5.x/6.0.0.1），材料写实际值；只有真跑过 6.0.0.1 才能写 6.0.0.1

## B WS63 星闪节点（两条路线，选一）

> **当前优先级（2026-10-17）**：**WS63 是主线**——先做双板近场确认器（协议/里程碑/演示见 [WS63 优先方案](06-WS63优先方案.md)）；RK3568 主设备后置且可选。

> **已确认板型（2026-10-17 拍照 + 厂商图）**：华清远见「鸿蒙星闪开发板」**FS-Hi3863DB_V2**（核心模块 **H3863-1.2 = Hi3863/WS63**，WiFi 6 + SLE + BLE）；丝印 `FS_H3863DB_V2`。板载：**0.96" SSD1306 OLED（I2C，IO15/IO16）**、用户键 KEY2、复位键 KEY1、蜂鸣器、NFC 碰一碰（type-2 tag）、USB-UART（SW1 切换串口）、SHT20 温湿度、AP3216 光感/接近/红外、RGB 灯、I2C0/1、UART0–2、PWM0–7、ADC0–5 排针。**第二块型号待核**。
> **资料获取**：板背右二维码“扫码免费领取开发板全套资料”（手机扫）；左二维码 = `http://yyzlab.com.cn`；华为开发者社区[案例页](https://developers.hisilicon.com/cn/caselibrary/34/huaqinyuanjian_ws63kfb)/[介绍帖](https://developers.hisilicon.com/postDetail?tid=0268176456950600001)。
> **屏幕（已确认）**：板载 **0.96" SSD1306 OLED，I2C，IO15/IO16**；旁边的 `SPI LCD` 排线座是**可选外接 ILI9341 屏**（`base_07_spi_lcd`），不是板载屏。
> **串口/烧录（已确认）**：`SW1=0` → USB 接 UART0、板载 RX/TX 接 UART2（**调试/烧录用这个**）；`SW1=1` → USB 不接串口、板载 RX/TX 接 UART0。UART0 = GPIO17/18，**115200 8N1**。
> **采购口径**：OLED/按键/蜂鸣器全板载，原 BOM 采购项作废（见 D 节）。

**源码**：
- 官方仓：`gitee.com/HiSpark/ohos_ws63`（基于 **OpenHarmony 5.1.0 Release** + WS63 SDK 1.10.101 裁减，28+ 示例含 SLE）
- FBB SDK：`gitee.com/HiSpark/fbb_ws63`（配套 HiSpark Studio，支持润和/小熊派多款板）

> **已取得的 SDK（2026-10-17）**：`fbb_ws63_20260226.7z`（242MB，2026-02-26），**已解压到 `D:\fbb_ws63_20260226`（1.2GB）**。内含 `vendor/Hqyj_Ws63` 板级支持包（原理图 `FS-WS63-原理图V2.pdf`、`ws63实验指导手册.md`）与 `Farsight` 例程（含 `sle_01_trans_server` / `sle_02_trans_client`）。
> **⚠️ 构建口径（2026-10-17 按实际 SDK 修正）**：该 SDK 的构建目标是 **`ws63-liteos-app`（LiteOS）**，且 HiSpark Studio 的 **Windows 路线只支持 LiteOS**（官方 tools 说明）。材料口径写“主设备 OH 4.x/5.x（实际版本）+ 星闪节点 WS63（LiteOS / fbb_ws63）”；若坚持节点也上 OH 轻量系统，需改用 `ohos_ws63` + WSL 路线（本阶段不做）。

**路线 1（推荐先试）：Windows + HiSpark Studio（海思 IDE）**
- 安装时**勾选 Python 3.11.4**（用系统 Python 易挂）
- 新建工程时 **SDK 路径必须指到 `fbb_ws63/src` 这一层**（指错=建工程失败）
- 烧录：官方 burntool，**Chip 选 WS63**

**路线 2：WSL / Ubuntu 源码编译**
- `hb build -f` 流程；**已知坑**：
  - demolink 任务堆栈 **1000 → 4000**（不改会崩）
  - 不加 `printf_adapt` **串口无输出**
  - 需按指南改 `BUILD.gn` / `ohos.cmake` / `config.py`（加入 demolink/printf_adapt）
- Linux 烧写用 `xf_burn_tools`
- 速通参考：OpenHarmony 论坛「开箱即用的 WS63/WS63E 编译环境 + 快速烧录工具」帖

**【等板】验证里程碑**：① 点灯 ② 串口 printf ③ BLE 示例 ④ **SLE 示例**（第二块板到货后做**双板握手**）
**⚠️ 版本口径（2026-10-17 按实际 SDK 修正）**：当前用 **fbb_ws63（2026-02-26）**，构建目标 `ws63-liteos-app`，**节点固件 = LiteOS**；HiSpark Studio 的 Windows 路线只支持 LiteOS。材料里**分开写**："主设备 OH 4.x/5.x（实际版本）标准系统 + 星闪节点 WS63（LiteOS / fbb_ws63 SDK）"。若要用 OH 5.1.0 轻量系统，需换 `ohos_ws63` + WSL 路线（本阶段不做）。
