## 0. 录制前置（一次性）

| 项 | 要求 |
|---|---|
| 服务 | `npm start`（清空 SMTP/IMAP 环境变量，强制 FakeMailer） |
| 模型 | 顶栏显示 `deepseek-flash（云）` |
| 真板 | A=COM11（执行/中继），B=COM12（确认）；`NEARFIELD_PORT=COM11`、`ACTUATOR_PORT=COM11`、`DEVICE=ws63-B`、`ACTUATOR_DEVICE=ws63-A` |
| 窗口 | 普通窗口登录 `demo`（员工）；**无痕窗口**登录 `helper`（设备助手）——同一浏览器两个普通窗口会共用 Cookie |
| 风险 | 开始前风险分应为 0；若被历史演练抬高，先清理 `console_state` 或重启到干净状态 |
| 附件 | `C:\Users\Lenovo\Desktop\video-assets\old\agenda.txt`（21B，非敏感） |
| 画面标注 | 真板确认不需“模拟确认”；**邮件必须标“模拟发送”** |

## 7. 重录点与常见失败

1. **发起后 B 板没反应**：员工点「发起确认」只创建挑战；要在 `helper` 设备页再点「确认」才会下发。
2. **审批页旧卡太多**：切到「待确认」标签；开始前清掉历史冻结操作。
3. **长按被当取消**：轻点立即松手，<600ms。
4. **风险冻结**：历史演练分会累加；录制前把风险清零，否则外发会被“风险冻结”而不是走确认。
5. **邮件真的发出去**：启动时必须清空 SMTP 环境变量，走 FakeMailer；画面标「模拟发送」。
6. **两个窗口变成同一角色**：必须普通窗口 + 无痕窗口。
7. **挑战过期**：TTL 90 秒，设备页点「确认」后串口等待约 65 秒；改内容/按键要在窗口内完成。
