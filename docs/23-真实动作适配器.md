# 真实动作适配器（v0.22）

> 目标：把“答应做的事”和“真的做了”分开。邮件已经真实发送（v0.21）；
> 这一轮把**打印**和**删除**做成真实动作，设备控制保留到 WS63 阶段。

## 1. 打印（真实打印队列）

| 项 | 实现 |
|---|---|
| 适配器 | `src/print-adapter.cjs`：PowerShell `Out-Printer -Name <打印机>`，文件路径/打印机名只走环境变量，避免命令注入 |
| 配置 | `SAFE_OFFICE_PRINTER=HP LaserJet MFP M232-M237`（本机实测打印机）；不填 → `simulated`，不冒充真打印 |
| 内容 | `_freezeDeferred` 把**文档正文冻进操作记录**，确认/重启后打印的是同一份内容 |
| 结果 | `printed` = 已提交打印队列；`failed` + printer not found → rejected；其他 → unknown |
| 审计 | `printJobs` 记录 `mode`（printed/simulated）与 printer 名 |

**实测（2026-10-30）**：`printText` 返回 `{"mode":"printed","printer":"HP LaserJet MFP M232-M237"}`；
`Get-PrintJob` 显示 Job Id 2 已入队。**只证明进了队列，不证明纸张真的出来**。

## 2. 删除（真删导入库）

- 导入资料：`DocumentStore.delete(docId)` + `unregisterDocument(docId)`，重启不会“复活”
- 内置样例文档仍是静态资源，删除只记 `deletedDocIds`（不破坏样例库）

## 5. 边界

- 打印编码由 Windows 驱动决定；中文可能受驱动/字体影响。
- 打印只支持纯文本；没有 PDF/排版。
- 删除只覆盖导入库；样例文档不可真删。
- 设备控制仍是模拟，等硬件。
