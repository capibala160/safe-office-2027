## 4. 串口 / 跳线 / 供电备忘

- **SW1（拨码）**：`0` → USB 接 UART0、板载 RX/TX 接 UART2（**调试/烧录用 0**）；`1` → USB 不接串口、板载 RX/TX 接 UART0。默认位置（拍照）：____
- **USB 口**：左侧“调试 下载”Micro-USB（USB 转 UART）
- **供电**：USB / 3V3 端子 / 电池；开关机拨动开关 S1
- **串口参数**：UART0 = GPIO17/18，**115200 8N1**
- **按键**：KEY1 = 复位；KEY2 = 用户键（**只有 1 个用户键** → 确认/取消用短按/长按）

- **屏幕接口与引脚**：**I2C，SDA/SCL = IO15/IO16**；从地址 0x3C 或 0x3D（取决 D/C）

## 5. 踩坑记录

> 格式：日期 / 现象 / 根因 / 解法

| 日期 | 现象 | 根因 | 解法 | 关联 |
|---|---|---|---|---|
| 2026-10-17 | Python 静默安装报 `Could not access network location D:Python311` | Git Bash 吞掉了 `D:\Python311` 的反斜杠 | `TargetDir` 用单引号包成 `'D:\Python311'` | 环境 |
| 2026-10-17 | 安装弹窗 “A newer version of the Python launcher is already installed” | 系统已有更新版 py launcher | 点“确定”继续，或加 `Include_launcher=0`；本次中断后用 `ensurepip` 补 pip | 环境 |
| 2026-10-29 | `hsflash` 报 `Shakehand failed, The board does not respond` | **没人按复位**：工具只等 30 秒，不会自己拉 DTR | 工具启动后**按一次 KEY1**，按完松手 | 烧录 |
| 2026-10-29 | 烧到 app 镜像随机断（0% / 3.6% / 37% / 100% 都有） | 传输期间**再次按复位或拨 S1** 会打断 ymodem | 只按一次；传输开始后手离开 | 烧录 |
| 2026-10-29 | 抓串口报 `PermissionError(13)`，COM11 消失 | **S1 关机会连 CH340 一起断电**，USB 设备重新枚举 | 断电只能做烧录前的准备，不能与烧录并行；重上电后等 COM 口回来 | 烧录 |
| 2026-10-29 | 编译报 `multiple definition of task1_ID` | `base_01_ledblink` 与 `base_03_ssd1306` 都定义了 `task1_ID` 和 `app_run`，且旧目标文件还在 `libsamples.a` 里 | 两个样例二选一（改 `application/samples/CMakeLists.txt` 的 `add_subdirectory_if_exist`），并删掉 `output/.../application/samples/libsamples.a` 与 `CMakeFiles/samples.dir/base_01_ledblink/` 再编 |
| 2026-10-29 | 115200 / 921600 各种失败组合 | 稳健组合 = `-b 921600 --switch-after-loader --before-reset --after-reset`，成功率约 50%，失败重试即可 | 每次重试都要重新按一次 KEY1 | 烧录 |
