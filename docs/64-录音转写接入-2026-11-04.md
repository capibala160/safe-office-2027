# 录音转写接入（v0.51，2026-11-04）

> 目标：把 `transcribeAudio` 从「固定文本模拟」换成**腾讯云一句话识别**（SentenceRecognition）。
> **音频会出端**，因此只处理「公开」级录音、必须显式配置与触发；转写文本仍按不可信输入过闸1。

## 1. 链路

```
文件页上传音频（wav/mp3/m4a，≤60 秒，≤5MB）
  → data/audios/<id>.<fmt>（0600）
  → POST /api/audios/:id/transcribe
  → 腾讯云 ASR（TC3 签名，16k_zh）
  → 文本过闸1（注入句隔离）
  → knowledge「tr_<id>（转写稿）」+ 审计（录音上传 / 录音转写 / 转写 或 闸1触发）
```

## 2. 配置（config.env，默认关闭）

```ini
SAFE_OFFICE_ASR=1
SAFE_OFFICE_ASR_PROVIDER=tencent
TENCENT_ASR_SECRET_ID=...
TENCENT_ASR_SECRET_KEY=...
TENCENT_ASR_REGION=ap-guangzhou
TENCENT_ASR_ENGINE=16k_zh
# 可选：SAFE_OFFICE_AUDIO_DIR=data/audios
```

未开启或密钥不全时：控制台保持模拟文案，上传接口返回 409 并提示配置。密钥只在本机 `config.env`（gitignore），不入库。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/audios` | 列出自己上传的录音（管理员/审计员可见全部） |
| POST | `/api/audios` | `{filename, data(base64), title, level}`，只接受 `level=公开` |
| POST | `/api/audios/:id/transcribe` | 调用云 ASR，返回 `{text, tainted, reasons, requestId, transcriptId}` |

## 4. 安全边界

- **音频出端**：只收「公开」级；`内部 / 机密` 一律 403（避免把敏感录音发给云）。
- 格式与魔数校验（RIFF/WAVE、ID3/帧同步、ftyp）、≤5MB；云侧限制 ≤60 秒。
- 转写文本**一律过闸1**；检出注入时整句隔离、`tainted=true`，并写「闸1触发」审计。
- 归属隔离：只能转写自己上传的录音；管理员/审计员例外。
- 审计记录 provider 与 `requestId`，可对账。
- **边界**：不证明说话人身份；不支持长音频/实时流（混元 ASR 未接）；上传文件落在 `data/audios/`，
  `reset()` 只清内存索引、不清文件（孤儿文件可手工删）。

## 5. 验证

- **真实密钥 + 真实音频**：`npm run asr:probe -- --file <mp3>` → `text="啊，你好。"`，返回 requestId。
- **浏览器全链路**：`node e2e/audio-check.cjs <mp3>` → 文件页上传 → 云端转写 → `tr_AUD-…` 入知识库（2026-11-04 通过）。
- 单测：格式/魔数、TC3 签名稳定性、载荷、错误映射、开关；
  运行时：真实 ASR 文本过闸1、注入隔离；接口：上传 → 转写（stub）。
- 全量：**568 项（566 通过 + 2 跳过）+ 11 E2E**。
- ⚠️ 未做：长音频（>60 秒）、实时流（混元 WebSocket）、说话人分离。
