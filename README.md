## 命题原文（国创赛官方页，2026-10-15 逐字核对）

> 基于 OpenHarmony 6.0.0.1 Release 版本，围绕智慧办公场景中的智能体运行与数据处理过程，完成面向智慧办公场景设计并实现一个具备 Agent 安全防护与治理能力的解决方案；围绕办公智能体执行过程中的安全问题，设计一套适用于智慧办公场景的 Agent 安全运行机制。

## 一句话方案

让办公智能体在**可管控、可确认、可审计**的边界内干活：
**防护**（注入拦截 / 工具越权拒绝 / 数据外泄防控）+ **治理**（策略中心 / 全链路审计 / 风险评分 / 可视化）+ **物理锚点**（WS63 星闪近场确认，高危操作必须持有设备主动确认）+ **沙箱与模型边界**（执行环境独立一锁；机密正文不进云），用多场攻防演示说话。

## 官方要求覆盖（摘要 · 详见设计骨架 §1）

- **基本目标 4/4**：办公能力安全调用控制 ✓｜文本/语音/**图片**输入输出安全检测 ✓｜风险识别分级处置与确认 ✓｜审计记录与**可视化** ✓

## 口径纪律

1. 底座表述一字不差：**「基于 OpenHarmony 6.0.0.1 Release」**；主设备=标准系统（6.0.0.1），星闪节点=轻量系统（官方 SDK 基线 OH 5.1.0）——**分开说，不混写**
2. 只写做出且验证过的功能；未完成的标"设计中/规划中"
3. 系统层改造默认不做（走"应用层 + 系统应用层"），除非评审明确要求
4. 模型部署口径：**端云协同**——机密文档正文不进云侧模型（分级分流+审计留痕），安全策略全部在端侧
5. 时间冲突纪律：2027 年 8–11 月撞考研冲刺 → 毕设合并 / 组队分担，提前定
6. **`engineering-master` 边界（2026-10-14 用户界定）**：智能建造文档审查平台**仅作思路借鉴**——不复用其代码/文档/场景素材/命名；本项目演示场景与全部素材自建
