## 命题原文

> 基于 OpenHarmony 6.0.0.1 Release 版本，围绕智慧办公场景中的智能体运行与数据处理过程，完成面向智慧办公场景设计并实现一个具备 Agent 安全防护与治理能力的解决方案；围绕办公智能体执行过程中的安全问题，设计一套适用于智慧办公场景的 Agent 安全运行机制。

## 一句话方案

让办公智能体在**可管控、可确认、可审计**的边界内干活：
**防护**（注入拦截 / 工具越权拒绝 / 数据外泄防控）+ **治理**（策略中心 / 全链路审计 / 风险评分）+ **物理锚点**（WS63 星闪近场确认，高危操作必须本人到场）——四层机制一体，用三场攻防演示说话。
